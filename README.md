# Voiceforge
### Voiceforge is a mod that allows you to change your voice 😃

### Version 1.0
### Note that voiceforge is lisenced!
Version 1.0 supports some features, goodness and simplicity all while being free! 💸
With a simple but rough UI you can customize and use only 1 voice at a time. 🎙️
With the little and simple features you can easily use it. 👍

## How to use:
1. Add your audios (MP3 On 1.X) 🔊
2. Open py file named app.py 📁
3. Configure settings to your liking ⚙️
4. Set microphone device in settings to your mic 🎙️
5. Set your mic to Voiceforge Mic 🥳

## Features:
• Get customizable pitch 🎚️  
• Virtual microphone output for supported applications 🎙️  
• Free goodness! 💸
